# Notepad

A simple, lightweight, and clean text editor inspired by classic Windows Notepad.

Perfect for quick notes, editing config files, or anyone who wants a fast, familiar text editor without bloat.

## Features

- Familiar Windows Notepad layout and behavior  
- Word Wrap toggle  
- Find (Ctrl+F) and Find Next (F3)  
- Insert Time/Date (F5)  
- Font selection  
- Full keyboard shortcuts (Ctrl+N, Ctrl+S, Ctrl+Z, etc.)  
- Status bar with line and column  
- Lightweight — starts instantly  
- Beautiful dark interface
